# Store-Bilder

Alle Bilder zeigen das echte Popup bzw. die echten Einstellungen mit **erfundenen Testdaten** (Dokumentations-IPs, `example.*`-Domains).

## Chrome Web Store – `chrome/de`, `chrome/en`

| Datei | Größe | Verwendung |
| --- | --- | --- |
| `screenshot-1.png` … `screenshot-5.png` | 1280×800 | Screenshots (max. 5), mit Überschrift |
| `promo-small-440x280.png` | 440×280 | Kleine Werbekachel (Pflicht) |
| `marquee-1400x560.png` | 1400×560 | Marquee (optional) |

Der Chrome Web Store erlaubt Screenshots je Sprache: `de` für den deutschen Eintrag, `en` für den englischen.

1. Übersicht – Module, gestörte Checks, DNS-Blockquote, öffentliche IP, Zertifikate
2. Healthchecks – Status, Antwortzeit, Prüfen/Pausieren, Filter
3. DNS64 – Pausieren, „Diese Seite“ freigeben/sperren, zuletzt blockiert, Cache leeren
4. DynDNS – IPv4/IPv6 kopieren, Ziele aktualisieren, Domains im ipv64.net-Konto
5. Hintergrund – Zähler am Symbol, Benachrichtigung, Rechtsklick-Menü

## Firefox Add-ons – `firefox/de`, `firefox/en`

1280×800, **ohne Überschriften**: Mozilla empfiehlt, Erklärungen nicht ins Bild zu schreiben, sondern in die Bildunterschrift. Auf addons.mozilla.org gibt es nur einen Satz Screenshots für alle Sprachen, die Bildunterschriften lassen sich aber übersetzen. Also einen Satz hochladen (`de` oder `en`) und die Unterschriften unten eintragen.

| Bild | Bildunterschrift (de) | Caption (en) |
| --- | --- | --- |
| 1 | Übersicht: Modulstatus, gestörte Checks, DNS-Blockquote, öffentliche IP und ablaufende Zertifikate | Overview: module status, failing checks, blocked DNS share, public IP and expiring certificates |
| 2 | Healthchecks mit Status und Antwortzeit – direkt prüfen oder pausieren | Health checks with state and latency – run or pause them right away |
| 3 | DNS64: Blockieren pausieren, die offene Seite freigeben oder sperren, zuletzt blockierte Domains erlauben | DNS64: pause blocking, allow or block the current site, unblock recently blocked domains |
| 4 | DynDNS: öffentliche IPv4/IPv6 kopieren, Updates anstoßen, Domains im ipv64.net-Konto | DynDNS: copy your public IPv4/IPv6, trigger updates, see your ipv64.net domains |
| 5 | Zähler am Symbol, Benachrichtigungen bei Ausfällen, Rechtsklick-Menü und Einstellungen | Badge on the icon, outage notifications, right-click menu and settings |
