# Datenschutzerklärung / Privacy Policy – Node64 Browser Extension

_Stand / Last updated: 15.11.2026_

## Deutsch

Die Node64 Browser Extension ist ein inoffizielles, quelloffenes Addon für Node64 und ipv64.net.

**Welche Daten werden gespeichert?**
Die von dir eingetragene Adresse deiner Node64, dein Node64-API-Key, optional dein ipv64.net-API-Key sowie deine Einstellungen (Abfrageintervall, Benachrichtigungen). Diese Daten liegen ausschließlich lokal in deinem Browser (`chrome.storage.local`) und werden nicht synchronisiert.

**Wohin werden Daten gesendet?**
Ausschließlich an
- die von dir eingetragene Node64-Adresse und
- `https://ipv64.net` (nur wenn du einen ipv64.net-API-Key einträgst).

Dabei wird der jeweilige API-Key zur Anmeldung mitgeschickt. Wenn du DNS64-Funktionen für die gerade geöffnete Seite nutzt, wird deren Domain (nicht die vollständige URL) an deine eigene Node64 gesendet. Anfragen gehen ohne Cookies raus.

**Was passiert nicht?**
Keine Analyse- oder Tracking-Dienste, keine Werbung, kein Verkauf oder Weitergabe von Daten an Dritte, keine Erfassung des Browserverlaufs. Der Entwickler erhält keinerlei Daten.

**Löschen:** Entferne die Keys in den Einstellungen des Addons oder deinstalliere das Addon – damit werden alle gespeicherten Daten gelöscht.

**Kontakt:** über die Issues im GitHub-Repository https://github.com/sakis-tech/node64-browser-extension

## English

The Node64 Browser Extension is an unofficial, open-source add-on for Node64 and ipv64.net.

**Stored data:** the Node64 address you enter, your Node64 API key, optionally your ipv64.net API key, and your settings. All of it is stored only locally in your browser (`chrome.storage.local`) and is not synced.

**Where data is sent:** only to the Node64 address you configured and to `https://ipv64.net` (only if you enter an ipv64.net API key), each authenticated with the respective API key. When you use the DNS64 actions for the current page, its domain name (not the full URL) is sent to your own Node64. Requests are sent without cookies.

**What does not happen:** no analytics or tracking, no ads, no selling or sharing of data with third parties, no collection of browsing history. The developer receives no data at all.

**Deletion:** remove the keys in the add-on settings or uninstall the add-on.

**Contact:** via GitHub issues at https://github.com/sakis-tech/node64-browser-extension
